# Decisión de licencia pendiente
No se ha elegido ni otorgado una licencia de código abierto en este paquete.
No se añadió un LICENSE ficticio ni se inventó autoría.

Pendientes de derechos y reutilización:
1. Confirmar quién posee los derechos de los archivos originales y derivados.
2. Elegir una licencia para el código que se puede licenciar y añadir LICENSE.
3. Confirmar por separado la redistribución de ajustes, datos y referencias numéricas.
4. Completar la autoría y la cita del proyecto en docs/CITACION.md.

Una licencia de código no otorga automáticamente derechos sobre PDFs, tablas
o material de terceros. Este paquete excluye PDFs y libros comerciales.
Consulta oficial: https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/licensing-a-repository
