# Contribuir
Cambios de física requieren fuente, ecuaciones, unidades, condición y validación.
No modificar coeficientes para forzar coincidencia con Lewis.
Añadir una regresión que detecte el error antes de corregirlo.
Conservar APIs/orden de estados y registrar cualquier diferencia de modelo.
Ejecutar verificar_publicacion (MATLAB) o verificar_publicacion.py (Python).
No incluir resultados, datos_locales, respaldos, PDFs ni credenciales en PRs.
Reportar MATLAB/Python/OS, comando, condición inicial, error y resultado esperado.
No asumir que una prueba omitida de tablas equivale a fidelidad verificada.
